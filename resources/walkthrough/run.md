## Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Build | <kbd>⌃⌘B</kbd> |
| Build & Run | <kbd>⌃⌘R</kbd> |
| Run Tests | <kbd>⌃⌘U</kbd> |
| Clean | <kbd>⌃⌘K</kbd> |
| Stop | <kbd>⌃⌘.</kbd> |
| Select Destination | <kbd>⌃⌘D</kbd> |

While a build runs, the status bar shows the live phase — Building → Linking →
Testing → Launching. When it finishes you get a ✓ or the exact error count;
click it to jump straight to the failing line.

Compiler errors, warnings and test failures also land in the **Problems** panel.
