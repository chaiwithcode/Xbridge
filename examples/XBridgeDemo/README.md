# XBridge Demo

A small, buildable SwiftUI app used to demonstrate XBridge in VS Code. It includes one XCTest and one Swift Testing test so both appear in Test Explorer.

1. Open this folder in VS Code on a Mac with Xcode installed.
2. Select the `XBridgeDemo` scheme and an iOS Simulator in the XBridge sidebar.
3. Use **Build & Run** to launch the app, or open Test Explorer and run both tests.

The app has no external packages or signing requirement for Simulator. Xcode build products and local VS Code settings are ignored by Git.
